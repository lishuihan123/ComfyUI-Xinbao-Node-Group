# 心宝❤构图

在节点内部把产品图放到背景图上，并自由调整位置、缩放和旋转。

## 操作

- **加载背景图**：设置底层背景。
- **加载产品图**：设置始终位于背景上层的产品图。
- **拖动产品**：改变位置。
- **拖动四角**：等比例缩放。
- **拖动顶部圆点**：旋转。
- **鼠标滚轮**：快速缩放。
- **锁定位置**：禁止误操作；执行节点后输出最终结果。

## 输出

- **拼合图**：背景与产品合成后的 IMAGE。
- **产品遮罩**：产品区域为白、背景区域为黑的 MASK。

透明 PNG 会按透明轮廓产生遮罩；没有透明通道的图片会以整张产品图片矩形产生遮罩。
