# 心宝♥外轮廓拼脸

输入底图、转好姿态的完整人物图，以及与姿态图同尺寸的脸部遮罩。节点只缩放、移动被抠出的图层，底图固定。

自动对齐只使用两侧脸颊、下颌、下巴的17个外轮廓点，不使用眼眉鼻嘴，不包含额头上缘。多个人脸、小脸或遮挡可能导致误检，请检查输出预览。

- `face_scale_percent`：自动对齐后额外缩放，默认0%，范围−20%～20%。围绕对齐后的脸部轮廓中心缩放。
- `offset_x` / `offset_y`：额外横向、纵向移动像素数。
- `scale_adjust`：额外缩放乘数，默认1；会与百分比缩放叠加。
- `align_tilt`：允许平面旋转；无法修正三维转头或俯仰。
- `preview_opacity`：仅调整对比预览透明度，不影响成片。

输出拼合图、变换后的遮罩、红/青轮廓叠加预览和报告。白色外描边由下游已有节点生成。

依赖 `rtmlib`、`onnxruntime`。两个检测模型需放在 `ComfyUI/models/pose/`：

- `yolox_m_8xb8-300e_humanart-c2c7a14a.onnx`
- `rtmw-x_simcc-cocktail14_pt-ucoco_270e-384x288-f840f204_20231122.onnx`

模型不会自动下载。迁移后请移走旧的 `xinbao_white_face_geometry` 独立插件，避免重复注册。
